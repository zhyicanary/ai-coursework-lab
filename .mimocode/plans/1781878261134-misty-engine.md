# 修改 vector_store.py 支持可配置 collection 名

## 目标
让 `common/vector_store.py` 支持传入 collection 名，解决 KnowSeeker 和 TripMind 知识库冲突问题。

## 修改文件
- `common/vector_store.py`

## 修改内容

### 1. 修改 `init_collection()` 函数
```python
def init_collection(collection_name: str = "default"):
    """初始化/获取 collection"""
    return client.get_or_create_collection(
        name=collection_name,
        metadata={"hnsw:space": "cosine"},
    )
```

### 2. 修改 `add_attractions()` 函数
添加 `collection_name` 参数：
```python
def add_attractions(city: str, attractions: list[dict], texts: list[str], collection_name: str = "attractions"):
```

### 3. 修改 `search_attractions()` 函数
添加 `collection_name` 参数：
```python
def search_attractions(city: str, query: str, top_k: int = 10, preferences: list[str] = [], collection_name: str = "attractions"):
```

### 4. 创建便捷函数（可选）
为两个项目创建专用函数：
```python
# KnowSeeker 专用
def add_documents(doc_id: str, documents: list[dict], texts: list[str]):
    """添加文档到知识库"""
    collection = init_collection("documents")
    ...

def search_documents(query: str, top_k: int = 5):
    """搜索文档知识库"""
    collection = init_collection("documents")
    ...
```

## 使用方式

### KnowSeeker（课设一）
```python
from common.vector_store import add_documents, search_documents
add_documents("doc1", documents, texts)
results = search_documents("什么是RAG")
```

### TripMind（课设二）
```python
from common.vector_store import add_attractions, search_attractions
add_attractions("成都", attractions, texts)  # 默认 collection="attractions"
results = search_attractions("成都", "历史文化景点")
```
